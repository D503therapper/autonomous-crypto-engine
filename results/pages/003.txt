Injury report
Boise State had two starters go down with injuries against Utah State: running back Dylan Riley and wide receiver Rasean Jones.

Their status for Saturday's game is up in the air, according to Boise State coach Spencer Danielson.
Danielson told reporters this week that he was optimistic about the return of several players — running back Sire Gaines, wide receiver Cam Bates, linebacker Logan Brantley and offensive lineman Carson Rasmussen — against the Bulldogs. In the latest injury report listed below, it appears Gaines is back for the Broncos.
The biggest question going into the game is the availability of Fresno State running back Rayshon Luke.
Luke left Saturday's game against Washington State because of a concussion.

Predictions
Fresno State needs to start fast and score touchdowns if it wants to upset Boise State.
While the Bulldogs scored just three points in the first quarter against Washington State, that approach probably won't work against Boise State. Fresno State needs to score an offensive touchdown in the first quarter and set the tone.
